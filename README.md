# CWHDS

A simple and beginner-friendly data science practice project focused on cleaning data, exploring datasets, and building basic recommendation-style ideas using Python and Jupyter notebooks.

## Project Overview

This repository contains a collection of notebooks and sample JSON data files used for learning and practicing common data science tasks such as:

- Data loading and inspection
- Data cleaning and preprocessing
- Working with structured and semi-structured data
- Building simple recommendation-based logic
- Practicing notebook-based analysis workflows

## Project Files

- 01Introduction.ipynb — introduction to the project and workflow
- 02data_Cleaning.ipynb — data cleaning and preprocessing steps
- 03_people_you_may_know.ipynb — simple social recommendation-style practice
- 04_pages_you_might_like.ipynb — content recommendation-style practice
- prk.ipynb — additional practice notebook
- data.json, data2.json, cleaned_data2.json, massi_data.json — sample datasets used throughout the project

## What You Will Learn

- How to work with JSON data in Python
- How to clean and prepare data for analysis
- How to explore data through notebooks
- How to build basic recommendation logic using simple patterns
- How to document and present a data science workflow clearly

## Setup

1. Install Python 3.x
2. Install Jupyter Notebook or JupyterLab
3. Install common data science packages such as:
   - pandas
   - numpy
   - matplotlib
   - seaborn
   - Scikit-Learn
4. Open the notebooks in order and run the cells step by step

## Recommended Workflow

1. Start with the introduction notebook
2. Move to the data cleaning notebook
3. Explore the recommendation-related notebooks
4. Review the datasets and experiment with your own ideas

## Notes

This project is intentionally simple and educational. It is designed for practice, experimentation, and learning core data science concepts rather than for production deployment.
